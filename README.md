# JSL Events · New Year Party 2026/27

Public event website for 31 December 2026 at ONO Bern.

- Website: https://joshua-lehmann.github.io/jsl-new-year-party-2026/
- Repository: https://github.com/joshua-lehmann/jsl-new-year-party-2026

## Stack

Static HTML generated by a small Node.js build, CSS and inline SVG. Zero client-side JavaScript, tracking, backend, database or accounts. Fonts (Bebas Neue / DM Sans) are self-hosted; their OFL licences are copied alongside the font assets. Sharp generates a 1200×630 PNG sharing image from public event data. GitHub Pages provides free hosting with automatic deployment after successful checks, without manually configured secrets.

## Develop and check

Requires Node.js 22+ and Python 3 for the optional preview server.

```sh
npm ci
npm run dev
# http://localhost:4173
npm run agent-check
```

The preview is static: run `npm run build` again after edits, then refresh. `npm run agent-check` runs regression tests with coverage, builds the site, checks formatting, and runs Fallow. For a change-specific audit: `npx fallow audit --base HEAD --coverage coverage/coverage-final.json` before committing (or use the relevant comparison commit).

## Edit content and links

All public content is in `src/event.mjs`:

- `ticketUrl`: the final Eventfrog event URL.
- `photoUploadUrl`: the Dropbox file request URL.
- `songVotingUrl`: currently empty. Add the confirmed HTTPS Spinlist event URL to automatically replace the pending message with **Songs wählen & abstimmen**. Blank, missing, null, malformed or insecure values stay pending with no fake button.
- `songVotingPlatform` and `votesPerGuest`: currently Spinlist and 2–3. Set the actual vote allowance in Spinlist; this website does not enforce it.
- `eventDate`, `eventEnd`, `timeZone`, `ticketPrice`, `venue`, and `copy`: event details and text. Dates include the Swiss winter offset; the site formats them in Europe/Zurich.
- `siteUrl`: full public URL, including trailing slash. Update when changing hosting; it controls canonical, sharing-image and sitemap URLs.

The confirmed end time is **03:30 on 1 January 2027**. The website intentionally uses its own design rather than displaying an older flyer with a different finish time. Do not add internal organisational notes, costs, personal contacts or guest capacity to public files.

## Deployment

Push to `main`. `.github/workflows/pages.yml` validates and builds, uploads only `dist/`, then publishes through GitHub Pages. Pull requests validate but cannot deploy. No paid hosting or manually configured API secret is required. The first deployment used GitHub Pages because no authenticated Cloudflare account was available.

For another static host, run `npm run build` and publish `dist/`. Asset references are relative and support project subpaths. `public/_headers` provides optional security headers for hosts that support that convention (Cloudflare Pages / Netlify); GitHub Pages does not apply that file. No application correctness depends on those headers.

## Verification

See `docs/acceptance.md` for invariants and `docs/verification.md` for browser checks. Node tests cover missing/unsafe/configured voting URLs, external links, Swiss date/time formatting, metadata and HTML escaping. No test purchases tickets or uploads guest files.

Fallow configuration explicitly lists the Node test files and copied CSS entry. Fontsource packages are used as build-time file assets through `require.resolve`, which static dependency analysis cannot infer from the copy loop; they are the only dependency exclusions. Actual Istanbul test coverage informs the complexity report.
